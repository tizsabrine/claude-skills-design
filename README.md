# claude-skills-design

A collection of Claude skills I've built for my product design work. Each skill gives Claude deep, specialized knowledge for a specific design task. Install it once, invoke it from any project or chat.

---

## How to install a skill

1. Download the skill folder
2. Drop it into your Claude skills directory: `~/.claude/skills/`
3. Claude picks it up automatically — no restart needed

---

## Skills

| Skill | What it does | When to use it |
|---|---|---|
| [pair-design](./pair-design) | Applies the full Google PAIR (People + AI Research) Guidebook to any AI feature or product. Outputs a structured `.md` file with 8 sections: AI value assessment, onboarding copy, mental model design, explainability & trust, feedback mechanisms, error taxonomy, reward function analysis, and sprint-ready next actions. Every section contains actual copy and specific decisions for your feature — not generic advice. | Describe any AI feature or product you're designing or reviewing. The skill outputs a `.md` file — paste it directly into Notion for a clean, readable brief. |
